# Technology Stack & Architectural Constraints

## 1. Agreed Technologies & Frameworks
- **Language / Runtime**: TypeScript 5+ on Node.js (v20+ LTS).
- **Frontend Framework**: Next.js 14+ (App Router with Server & Client Components).
- **Styling**: Tailwind CSS with standard accessible utility patterns and Lucide icons.
- **Data Stores & ORM**: SQLite via Prisma ORM (`@prisma/client`, `prisma`).
- **Validation**: Zod for runtime schema validation and API payloads.
- **Testing**: Vitest for unit & integration tests, React Testing Library for component tests.
- **Tooling & Package Manager**: `pnpm` (Fast, disk-efficient package management).

## 2. Architectural Decisions & Patterns
- **Layered Structure**:
  - `src/app/`: Next.js App Router routes, layouts, and page entry points.
  - `src/components/`: Modular React components separated by domain (`ui/`, `issues/`, `auth/`, `layout/`).
  - `src/server/`: Server-side actions, database queries, and data access logic.
  - `src/lib/`: Shared utilities, Prisma client instance, and validation schemas.
  - `src/types/`: TypeScript definitions and contract interfaces.
- **Authentication Strategy**: Database-backed sessions in SQLite via Prisma paired with secure HTTP-only cookies.
- **Data Access**: Prisma ORM with SQLite file database (`prisma/schema.prisma` and `dev.db`).

## 3. Engineering Constraints & Rules
- **File Modularity**: Strict rule: No source code, test, or markdown spec file may exceed 300 lines (excluding autogenerated files like lockfiles/client stubs).
- **Error Handling**: Explicit return types and error boundaries; no unhandled promise rejections.
- **Traceability**: All business logic functions and endpoints must correspond to a specification acceptance criterion.
- **Testing**: Automated test suite run via `pnpm test` must pass before marking any phase done.

## 4. Agentic Architecture & Skills Integration
Agent workflows are codified as reusable skills in `.agents/skills/`:
- **Directory Structure**:
  - `.agents/skills/init-sdd/`: Constitutional setup.
  - `.agents/skills/feature-spec/`: Spec creation & alignment.
  - `.agents/skills/validate-feature/`: Independent auditor subagent for QA validation.
  - `.agents/skills/maintain-changelog/`: SDD changelog maintenance.
- **Subagent Delegation**: The `validate-feature` skill spawns an isolated auditor subagent (`feature-spec-validator`) to independently execute tests (`pnpm test`, `typecheck`, `lint`, `build`) and audit line length compliance before merging.

## 5. Deployment & Infrastructure
- **Target Environment**: Local Node.js runtime and Vercel/Node container-ready.
- **Database Storage**: Local file-based SQLite database with migration capabilities via Prisma Migrate.
